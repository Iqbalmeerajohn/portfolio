# Portfolio: Sheik Iqbal Meera John

Personal portfolio. Static HTML, CSS and vanilla JS with GSAP, ScrollTrigger and Lenis.

- Hero: a canvas particle field where points converge into the name, like vectors settling on a query. The cursor pushes them apart.
- Saree search replay: a real query and its top-5 results from the project's evaluation set.
- SALVAGE: the agent's 9-stage decision loop, with the policy gate highlighted.
- Respects `prefers-reduced-motion`.

Run locally: `python -m http.server` in this folder.
